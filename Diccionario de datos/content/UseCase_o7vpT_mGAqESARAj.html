Use Case Note
■ Workflow
    • El usuario consulta la lista o el detalle de una sede.
    • Presiona el icono o botón "Agregar a Favoritos".
    • El sistema valida que el usuario esté autenticado.
    • El sistema guarda la asociación entre la sede y el usuario en la base de datos.
    • La interfaz actualiza el estado visual indicando que la sede forma parte de sus favoritos.
■ Business Logic
    • Un usuario debe tener una sesión activa para poder agregar o quitar sedes de su lista de favoritos.
    • Una sede no puede duplicarse en la lista de favoritos de un mismo usuario.
    • Si la sede ya está guardada como favorita, la misma acción debe actuar como alternador (toggle) para removerla de la lista.
■ Decisions
    • La lista de favoritos se almacenará asociada a la cuenta del usuario en la base de datos para persistir entre sesiones.
■ Follow-up
    • Confirmar si en la vista principal de perfil o inicio se agregará un acceso directo con las "Mis Sedes Favoritas".

Scenario
Steps
1. El usuario visualiza la información de una sede deportiva.
2. El usuario hace clic en la opción "Guardar en Favoritos" (icono de estrella/corazón).
3. El sistema valida que el usuario se encuentre autenticado.
4. El sistema registra la sede en la lista de favoritos del usuario dentro de la base de datos.
5. El sistema actualiza la vista mostrando el indicador de "Favorito" activo y muestra una notificación rápida: "Sede agregada a tus favoritos".
