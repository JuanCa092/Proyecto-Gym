Use Case - Modificar perfil link

Properties
Name Value
Description

El caso de uso permite a un usuario autenticado consultar y actualizar la información de su perfil personal dentro de la plataforma GymLocator      . El usuario modifica los campos permitidos y el sistema valida e interactúa con la base de datos para almacenar los datos actualizados      .

Use Case Note
■ Workflow
    • El usuario ingresa a la sección "Mi Perfil".
    • El sistema carga y muestra los datos personales actuales registrados en la cuenta.
    • El usuario modifica los campos deseados (ej. correo electrónico o nombre) y hace clic en "Guardar Cambios".
    • El sistema valida la información e informa al usuario sobre la actualización exitosa.
■ Business Logic
    • Los campos obligatorios no pueden quedar vacíos durante la edición.
    • Si se modifica el correo electrónico, el sistema debe verificar que no pertenezca a otro usuario registrado.
    • Los datos deben ser validados sintácticamente (formato de e-mail correcto y documento numérico).
■ Decisions
    • Se permite la edición de nombres, correo y contraseña.
    • No se requiere reautenticación por contraseña para cambios simples de datos personales, pero sí confirmación para cambio de clave.
■ Follow-up
    • Confirmar si el cambio de correo electrónico requerirá un proceso de verificación por correo en futuras versiones (fuera del alcance académico actual)

Scenario
Steps
1. El usuario selecciona la opción "Mi Perfil" desde el menú de navegación.
2. El sistema despliega el formulario con la información actual del usuario.
3. El usuario modifica los datos en los campos habilitados y hace clic en "Guardar".
4. if El sistema valida la consistencia y formato de los datos ingresados. El sistema actualiza el registro del usuario en la base de datos.
   end if
5. El sistema muestra un mensaje de confirmación: "Perfil actualizado con éxito".
