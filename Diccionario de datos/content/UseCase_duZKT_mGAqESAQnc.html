Use Case - Registro usuario link

Properties
Name Value
Description

El caso de uso permite a un nuevo visitante registrarse en la plataforma GymLocator mediante el diligenciamiento de un formulario con sus datos básicos (nombres, documento de identidad, correo electrónico y contraseña)      . El sistema valida la información e ingresa el nuevo usuario en la base de datos para habilitar su posterior autenticación      .

Use Case Note
■ Workflow
    • El usuario no registrado hace clic en la opción "Registrarse" o "Crear Cuenta" de la aplicación web.
    • El sistema despliega la interfaz con el formulario de registro.
    • El usuario ingresa sus datos personales (nombres, documento, correo electrónico y contraseña) y envía el formulario.
    • El sistema valida la estructura y unicidad de los datos.
    • El sistema guarda el registro en la base de datos y muestra una notificación de éxito.
■ Business Logic
    • Todos los campos del formulario son obligatorios (Nombres, Documento, Correo, Contraseña).
    • El correo electrónico y el documento de identidad deben ser únicos en la base de datos (no se permiten duplicados).
    • La contraseña debe cumplir con los requisitos mínimos de seguridad definidos.
    • Al completarse el registro, al usuario se le asigna automáticamente el rol predeterminado de "Cliente/Usuario".
■ Decisions
    • No se enviará correo de activación ni verificación en dos pasos debido al alcance exclusivamente académico del proyecto.
    • Una vez registrado con éxito, se redirige al usuario a la pantalla de Inicio de Sesión (Login).
■ Follow-up
    • Validar con el equipo si tras registrarse exitosamente se debe iniciar la sesión de forma automática o redirigir obligatoriamente al login.

Scenario
Steps
1. El visitante navega hacia la opción "Registrarse" de la plataforma.
2. El sistema despliega el formulario de registro solicitando nombres, documento de identidad, correo electrónico y contraseña.
3. El usuario completa los campos con su información y presiona el botón "Registrar".
4. El sistema valida que los campos no estén vacíos y que los datos tengan la estructura correcta (formato de correo válido y documento numérico).
5. El sistema verifica que el correo y el documento no estén previamente registrados en la base de datos.
6. El sistema guarda la información del nuevo usuario en la base de datos.
7. El sistema confirma la creación del registro con el mensaje: "Usuario registrado con éxito" y redirige al formulario de inicio de sesión.
