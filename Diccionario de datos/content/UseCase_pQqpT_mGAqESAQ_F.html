Description

El caso de uso permite a un usuario autenticado cancelar una reserva previamente realizada sobre una clase deportiva, retirando el registro del usuario e incrementando en 1 el número de cupos disponibles para dicha clase      .

Use Case Note
■ Workflow
    • El usuario accede al listado de sus inscripciones activas.
    • Selecciona la clase que desea cancelar y presiona el botón "Cancelar Inscripción".
    • El sistema solicita la confirmación de la acción.
    • Al confirmar, el sistema elimina la reserva de la base de datos y aumenta la disponibilidad de cupos en la clase.
    • El sistema notifica la cancelación exitosa y actualiza la vista.
■ Business Logic
    • Solo el usuario propietario de la reserva (o un Administrador) tiene permisos para cancelarla.
    • La cancelación debe incrementar inmediatamente el número de cupos disponibles de la clase en +1.
    • Se requiere confirmación explícita por parte del usuario para evitar cancelaciones accidentales.
■ Decisions
    • No se aplican penalizaciones ni restricciones de tiempo límite para la cancelación debido al alcance académico del proyecto.
    • La acción elimina permanentemente el registro de reserva de la tabla de inscripciones del usuario.
■ Follow-up
    • Definir en versiones futuras si se habilitará un historial de inscripciones canceladas (fuera del alcance académico actual).

Scenario
Steps
1. El usuario navega a la sección "Mis Inscripciones".
2. El sistema muestra la lista de clases reservadas por el usuario.
3. El usuario elige una reserva y presiona la opción "Cancelar Inscripción".
4. El sistema despliega un mensaje modal solicitando confirmación: "¿Desea cancelar su inscripción a esta clase?".
5. El usuario selecciona "Confirmar".
6. El sistema elimina la reserva de la base de datos.
7. El sistema suma 1 cupo a la cantidad de cupos disponibles para esa clase.
8. El sistema muestra una notificación de confirmación: "Inscripción cancelada exitosamente" y remueve la clase de la lista visual.
