Columns Summary
Column Name Data Type PK / FK Nullable Description
id_cliente smallint(5) PK No

La id_cliente se crea para generar un identificador unico del cliente y relacionarse con otras entidades  

nom_cliente varchar(50) No

Registra el nombre del cliente para identificarlo y mostrarlo en el sistema

ape_cliente varchar(50) No

Complementa la identificacion personal del cliente y los diferencia con aquellos que usen un nombre igual

telefono varchar(255) No

permite contacto directo con el cliente

num_doc integer(10) No

el numero del documento real permite registrar el documento del cliente y facilitar su identificacion dentro del sistema

correo varchar(50) No

Es un medio el cual se añade al momento de registrarse, por el cual, se pueden enviar notificaciones al usuario para la verificación de contraseña, informe de cambio de datos, etc.

id_tipo_doc smallint(5) FK No

id_tipo_doc es un número único que se usa para  relacionar y específicar con que tipo de documento está registrado el cliente

estado varchar(10) No

El estado de disponibilidad de la cuenta del cliente
