Description

El caso de uso permite a un entrenador autenticado seleccionar un cliente o grupo de clientes inscritos en sus clases y vincularles una rutina de ejercicios predefinida o personalizada, registrando los detalles de la asignación en la base de datos      .

Use Case Note
■ Workflow
    • El entrenador accede al panel de gestión de clientes o al listado de inscritos de una clase.
    • Selecciona el cliente al cual desea prescribir el entrenamiento y presiona "Asignar Rutina".
    • El sistema despliega el catálogo de rutinas disponibles o el formulario de asignación.
    • El entrenador elige la rutina adecuada y confirma la acción.
    • El sistema guarda la asociación entre el cliente y la rutina en la base de datos y envía una notificación en pantalla.
■ Business Logic
    • El entrenador solo puede asignar rutinas a clientes que se encuentren registrados y vinculados a sus clases o sedes a cargo.
    • Un cliente puede tener una o varias rutinas asignadas activas en su perfil.
    • La asignación debe registrar la fecha en que se vinculó la rutina y el ID del entrenador autor.
■ Decisions
    • La interfaz permitirá seleccionar una rutina preexistente del banco de rutinas de la plataforma para agilizar el proceso.
■ Follow-up
    • Definir si el cliente recibirá un mensaje/alerta visual dentro de la app avisando que se le ha asignado una nueva rutina.

Scenario
Steps
1. El entrenador navega a la lista de clientes o lista de inscritos por clase.
2. El entrenador selecciona un cliente y hace clic en la opción "Asignar Rutina".
3. El sistema muestra la lista de rutinas/ejercicios preconfigurados en el sistema.
4. El entrenador elige la rutina correspondiente y presiona "Confirmar Asignación".
5. El sistema valida los datos y registra la vinculación entre el cliente y la rutina en la base de datos.
6. El sistema despliega el mensaje de confirmación: "Rutina asignada exitosamente al usuario".
