Use Case - Cerrar Sesión link

Properties
Name Value
Description

El caso de uso permite a un usuario con una sesión activa finalizar su sesión dentro de la plataforma GymLocator      . El sistema destruye la sesión del usuario, elimina los tokens o credenciales temporales de la memoria y redirige a la vista pública principal o a la pantalla de inicio de sesión      .

Use Case Note
■ Workflow
    • El usuario autenticado presiona el boton de cerrar sesion en la interfaz
    •
■ Business Logic
    • El sistema invalida la sesion activa y elimina los tokens de autenticacion almacenados del navegador
    •
■ Decisions
    • El comportamiento es el mismo para todos los roles del sistema.
    •
■ Follow-up
    • Definir si el sistema debe mostrar una notificación visual (Toast / Alerta) confirmando "Has cerrado sesión correctamente" al redirigir al login.
    •

Scenario
Steps
1. El usuario autenticado hace clic en el botón u opción "Cerrar Sesión" dentro de la plataforma.
2. El sistema recibe la instrucción de cierre y destruye la sesión activa del usuario.
3. El sistema elimina las credenciales y tokens de autenticación del estado del navegador.
4. El sistema muestra la notificación: "Sesión cerrada exitosamente" y redirige a la pantalla de inicio de sesión (Login).
