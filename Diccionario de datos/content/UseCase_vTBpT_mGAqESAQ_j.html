Use Case Note
■ Workflow
    • El usuario accede a la sección "Mis Inscripciones" o "Mis Clases" desde el menú del perfil.
    • El sistema consulta en la base de datos las reservas asociadas al identificador del usuario activo.
     El sistema despliega la lista con las clases reservadas y sus detalles (sede, horario, entrenador).
    • El usuario revisa la información de sus clases programadas.
■ Business Logic
    • Se requiere autenticación previa para consultar las reservas de la cuenta.
    • Solo se deben mostrar las inscripciones pertenecientes al usuario que tiene la sesión activa.
    • La lista debe presentar la información actualizada de las clases en tiempo real.
■ Decisions
    • En esta misma vista se habilitará la opción para acceder a la cancelación de la reserva (enlace al CU de Cancelación de inscripción).
■ Follow-up
    • Definir si a futuro se separarán las clases en pestañas de "Próximas" e "Historial/Pasadas" (fuera del alcance académico actual).

Scenario
Steps
1. El usuario navega a la sección "Mis Inscripciones" dentro de la plataforma.
2. El sistema valida la sesión activa del usuario.
3. El sistema busca en la base de datos todas las reservas vinculadas a la cuenta del usuario.
4. El sistema presenta el listado de clases reservadas ordenadas por fecha/horario con los datos de sede, especialidad y entrenador.
