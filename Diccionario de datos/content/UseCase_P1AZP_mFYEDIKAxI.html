Use Case - Modificar clases link

Properties
Name Value
Description

El caso de uso permite a un Administrador autenticado editar la información de una clase previamente creada en la plataforma GymLocator (nombre, entrenador asignado, sede, fecha, horario o aforo), actualizando los datos almacenados en el sistema.

Use Case Note
■ Workflow
    • El Administrador accede al módulo "Gestión de Clases" o "Agenda de Clases".
    • Selecciona la clase que requiere ajustes y presiona la opción "Editar" o "Modificar Clase".
    • El sistema despliega el formulario precompletado con la información actual de la sesión.
    • El Administrador realiza los cambios requeridos (ej. cambio de horario o reemplazo de entrenador) y presiona "Guardar Cambios".
    • El sistema valida la disponibilidad de la sede y del nuevo entrenador para evitar solapamientos.
    • El sistema registra la actualización en la base de datos y confirma el éxito de la operación.
■ Business Logic
    • Solo los usuarios con rol de Administrador tienen privilegios para editar clases creadas.
    • Si se modifica el número de cupos disponibles, la nueva cantidad no puede ser inferior a los usuarios que ya se encuentran actualmente inscritos/reservados en dicha clase.
    • La nueva fecha o rango horario asignado no debe generar cruce de agenda con otra clase del mismo entrenador o en la misma sede.
    • Decisions:
■ Decisions
    • La modificación actualizará la información en tiempo real en la vista pública de reservas del cliente.
■ Follow-up
    • Implementar un servicio de notificación (vía e-mail o alerta en app) que informe automáticamente a los clientes previamente inscritos en caso de cambios en el horario o sede de la clase.

Scenario
Steps
1. El Administrador navega al módulo "Clases".
2. El sistema muestra el listado de clases programadas.
3. El Administrador selecciona una clase y presiona "Modificar".
4. El sistema presenta el formulario de edición cargando los campos vigentes.
5. El Administrador efectúa las correcciones necesarias y presiona "Guardar Cambios".
6. El sistema invoca el caso de uso Verificar datos para validar los campos.
7. El sistema verifica que el ajuste no produzca cruces de horario para la sede o el entrenador.
8. El sistema actualiza el registro en la base de datos.
9. El sistema notifica: "Clase modificada exitosamente" y regresa a la vista de la agenda.
