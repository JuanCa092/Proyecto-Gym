Description

El caso de uso permite a un Administrador autenticado programar y registrar una nueva clase de entrenamiento en la plataforma, definiendo el nombre de la disciplina, la sede donde se dictará, el entrenador encargado, la fecha, el horario y el límite de cupos disponibles.

Use Case Note
■ Workflow
    • El Administrador accede al módulo "Gestión de Clases" dentro del panel de administración.
    • Presiona el botón "Crear Clase".
    • El sistema despliega el formulario de creación de clases.
    • El Administrador selecciona la sede, el entrenador responsable, e ingresa el nombre de la clase, fecha, hora de inicio/fin y cupos máximos.
    • El sistema valida la disponibilidad de la sede y del entrenador en ese horario, así como los datos ingresados.
    • El sistema guarda la clase en la base de datos y publica la disponibilidad para reservas.
■ Business Logic
    • Solo los usuarios con rol de Administrador tienen permisos para crear y programar clases.
    • Todos los campos (Sede, Entrenador, Nombre de la clase, Fecha, Hora inicio, Hora fin y Cupos) son obligatorios.
    • El entrenador seleccionado debe estar previamente dado de alta en la plataforma.
    • Un entrenador no puede tener dos clases programadas en el mismo rango de fecha y horario.
    • Los cupos máximos no pueden exceder el aforo total permitido para la sede seleccionada.
■ Decisions
    • Una vez creada la clase, quedará visible de forma inmediata en el catálogo público para que los clientes puedan inscribirse.
■ Follow-up
    • Verificar en la lógica de backend el solapamiento de horarios tanto de las sedes como de la agenda del entrenador.

Scenario
Steps
1. El Administrador navega hacia el módulo "Gestión de Clases".
2. El Administrador hace clic en "Crear Clase".
3. El sistema muestra el formulario solicitando nombre de la clase, sede, entrenador, fecha, horario y cupos.
4. El Administrador diligencia los campos y presiona "Guardar Clase".
5. El sistema ejecuta el caso de uso Verificar datos para validar la consistencia de las entradas.
6. El sistema verifica que no existan cruces de horario para el entrenador ni para la sede seleccionada.
7. El sistema almacena el registro de la clase en la base de datos.
8. El sistema muestra la notificación: "Clase creada exitosamente" y actualiza la lista de la agenda.
