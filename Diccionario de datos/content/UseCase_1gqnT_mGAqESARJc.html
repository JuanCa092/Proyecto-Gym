Use Case - Registrar entrenadores link

Properties
Name Value
Description

El caso de uso permite a un Administrador autenticado dar de alta a un nuevo entrenador en la plataforma GymLocator mediante el diligenciamiento de sus datos personales, credenciales de acceso y especialidad deportiva, asignándole automáticamente el rol de "Entrenador" en la base de datos.

■ Workflow
    • El Administrador accede a la sección "Gestión de Entrenadores" dentro del panel administrativo.
    • Selecciona la opción "Registrar Entrenador".
    • El sistema despliega el formulario de registro especializado para el personal técnico.
    • El Administrador ingresa los datos requeridos (nombres, documento, correo, contraseña temporal, especialidad/sede).
    • El sistema valida que los datos cumplan con las reglas de negocio y no existan duplicados en la base de datos.
    • El sistema crea el perfil con rol de "Entrenador" y muestra la confirmación de registro.
■ Business Logic
    • Solo los usuarios con rol de Administrador están autorizados para registrar entrenadores.
    • Todos los campos obligatorios del registro (Nombres, Documento, Correo, Contraseña y Especialidad) deben ser validados.
    • El documento de identidad y el correo electrónico del entrenador no pueden estar previamente registrados en el sistema.
    • Al usuario creado se le asignará el rol del sistema Entrenador para delimitar sus permisos a las vistas correspondientes.
■ Decisions
    • La contraseña asignada por el Administrador será de primer acceso, permitiendo al entrenador iniciar sesión directamente.
■ Follow-up
    • Definir si se enviará una notificación por correo al entrenador notificando la creación de su cuenta institucionales.

Scenario
Steps
1. El Administrador navega hacia el módulo de "Gestión de Entrenadores".
2. El Administrador presiona el botón "Registrar Entrenador".
3. El sistema muestra el formulario de alta pidiendo nombres, documento, correo, contraseña inicial y especialidad.
4. El Administrador completa los campos y presiona "Guardar Registro".
5. El sistema invoca los casos de uso Verificar datos y Verificar usuarios existentes para validar la información.
6. El sistema guarda la información del nuevo entrenador en la base de datos asignándole el rol correspondiente.
7. El sistema confirma con la notificación: "Entrenador registrado exitosamente" y actualiza la lista del personal.
