Description

El caso de uso permite a un entrenador autenticado consultar la lista de clases deportivas que le han sido asignadas por el administrador, permitiéndole revisar la sede, especialidad, horario, fecha y número de cupos/asistentes registrados en cada sesión      .

Use Case Note
■ Workflow
    • El entrenador inicia sesión y accede a la sección "Mis Clases Asignadas" o "Mi Agenda".
    • El sistema identifica al entrenador autenticado a través de su token o ID de usuario.
    • El sistema consulta en la base de datos únicamente las clases donde dicho entrenador está registrado como responsable.
    • El sistema despliega la lista o agenda con la información completa de sus sesiones programadas (sede, horario, especialidad y cupos ocupados)
■ Business Logic
    • La consulta requiere autenticación previa con rol de "Entrenador".
    • El entrenador solo puede visualizar las clases asignadas a su perfil, no las de otros instructores (a menos que consulte el catálogo general público).
    • La lista debe actualizarse en tiempo real reflejando los cupos ocupados o cancelaciones realizadas por los clientes.
■ Decisions
    • La vista mostrará las clases ordenadas cronológicamente por fecha y hora de la sesión.
    • Se incluirán filtros rápidos por sede si el entrenador dicta clases en múltiples ubicaciones de la red.
■ Follow-up
    • Evaluar si en versiones posteriores se permitirá al entrenador exportar su agenda de clases a un formato de calendario o PDF (fuera del alcance actual).

Scenario
Steps
1. El entrenador navega a la sección "Mis Clases Asignadas" desde su panel de control.
2. El sistema valida el rol del usuario activo.
3. El sistema busca en la base de datos todas las clases vigentes donde el ID del entrenador coincida con el instructor asignado.
4. El sistema presenta la agenda de clases mostrando la sede, especialidad, día, horario y la cantidad de inscritos/cupos disponibles.
