Use Case - Agregar entrenador link

Properties
Name Value
Description

El caso de uso permite a un Administrador autenticado vincular un perfil de entrenador registrado previamente a una sede específica de la red GymLocator, definiendo su disponibilidad y perfil operativo en dicha ubicación.

Use Case Note
■ Workflow
    • El Administrador accede a la sección "Gestión de Sedes" o "Gestión de Entrenadores".
    • Selecciona la opción "Agregar/Asignar Entrenador a Sede".
    • El sistema despliega el listado de entrenadores activos registrados en la plataforma.
    • El Administrador selecciona el entrenador y la sede correspondiente.
    • El sistema valida que la vinculación no exista previamente en la base de datos.
    • El sistema registra la asociación y muestra un mensaje de confirmación.
■ Business Logic
    • Solo el usuario con rol de Administrador está autorizado para vincular entrenadores a las sedes.
    • El entrenador debe haber sido registrado previamente en la plataforma a través del flujo correspondiente (Registrar entrenadores).
    • No se permite duplicar la vinculación activa de un mismo entrenador en una misma sede.
    • Un entrenador puede estar asociado a múltiples sedes de la red GymLocator.
■ Decisions
    • La vinculación habilitará de inmediato al entrenador en las listas desplegables al momento de programar o crear clases en la sede asignada.
■ Follow-up
    • Confirmar si la desvinculación o remoción de un entrenador de una sede cancelará automáticamente las clases futuras en las que esté programado.

Scenario
Steps
1. El Administrador ingresa al módulo de administración de sedes o personal.
2. El Administrador selecciona la opción "Agregar Entrenador a Sede".
3. El sistema muestra la lista de entrenadores registrados y el catálogo de sedes disponibles.
4. El Administrador elige el entrenador, selecciona la sede destino y presiona "Guardar Asignación".
5. El sistema valida que el entrenador no esté previamente asociado a esa sede.
6. El sistema guarda la relación en la base de datos.
7. El sistema confirma la acción con el mensaje: "Entrenador agregado exitosamente a la sede" y actualiza la lista del personal de la sede.
