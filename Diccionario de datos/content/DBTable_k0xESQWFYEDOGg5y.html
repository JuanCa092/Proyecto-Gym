Properties
Name Value
Description

Una clase es un evento en el que se puede inscribir el usuario para participar en ejercicios en grupo

Data Model Physical
Primary Key Clustered Unspecified
Unlogged false
Temporal false

Columns Summary
Column Name Data Type PK / FK Nullable Description
nom_clase varchar(10) No Es el nombre con el que una clase se identifica o es registrada en el servidor
num_cupo integer(10) No

Se usa para saber la capacidad/aforo máximo de un entrenamiento (depende del tamaño físico del gym)

descripcion varchar(100) No

Permite dar un breve resumen del tipo de entrenamiento en la que se epecializa el evento

estado varchar(10) No

Permite revisar el estado de la clase, entre activa (vigente), inactiva, cancelada o pasada

categoría integer(10) No

Es el tipo de enttrenamiento en el que se especializa la clase seleccionada (spinning, musculación, cardio, etc...)

id_entrenador smallint(5) FK No

id_entrenador se usa para relacionar la clase de enertenamiento con el entrenador que se le fue asignado

id_clase_entr smallint(5) PK No

El id_clase es un número único que se usa para registrar una clase

id_tipo_cat smallint(5) FK No

id_tipo_cat es una relación que se usa para saber el número único que se generó al crear el entrenamiento

id_sede smallint(5) FK No

id_sede es la relación se usa para saber específicamente el gimnasio en el que llevará a cabo la clase de entrenamiento mediante el número único que se le asignó a la sede al registrarse en el servidor
