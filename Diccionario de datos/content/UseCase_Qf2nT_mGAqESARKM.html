Description

El caso de uso permite a un Administrador autenticado dar de alta una nueva sede deportiva en la plataforma GymLocator, ingresando datos fundamentales como nombre de la sede, dirección física, teléfono de contacto, horario de atención y aforo o capacidad máxima.

Use Case Note
■ Workflow
    • El Administrador accede al módulo "Gestión de Sedes" dentro del panel de administración.
    • Presiona el botón "Agregar Nueva Sede".
    • El sistema muestra la interfaz con el formulario de registro de la sede.
    • El Administrador completa los campos requeridos (nombre, dirección, teléfono, horario y capacidad).
    • El sistema valida que los datos ingresados sean correctos y que la sede no esté registrada.
    • El sistema almacena la nueva sede en la base de datos y despliega el mensaje de confirmación.
■ Business Logic
    • Solo los usuarios con rol de Administrador tienen permisos para crear sedes.
    • Todos los campos principales del formulario (Nombre, Dirección, Teléfono y Capacidad) son obligatorios.
    • El nombre y la dirección de la sede no deben coincidir con una sede previamente existente en el sistema.
    • La capacidad máxima (aforo) debe ser expresada obligatoriamente como un valor numérico entero positivo.
■ Decisions
    • Una vez creada la sede, quedará activa de forma inmediata en el catálogo público para que los clientes puedan consultarla.
■ Follow-up
    • Evaluar si en versiones posteriores se permitirá cargar una foto descriptiva de la sede al momento de su creación.

Scenario
Steps
1. El Administrador navega hacia el módulo "Gestión de Sedes".
2. El Administrador selecciona la opción "Crear Sede".
3. El sistema despliega el formulario pidiendo nombre, dirección, teléfono de contacto, horario y capacidad.
4. El Administrador completa la información y presiona "Guardar Sede".
5. El sistema invoca el caso de uso Verificar datos para corroborar la validez de las entradas.
6. El sistema guarda la nueva sede en la base de datos.
7. El sistema confirma la acción con el mensaje: "Sede creada exitosamente" y actualiza el listado global de sedes.
