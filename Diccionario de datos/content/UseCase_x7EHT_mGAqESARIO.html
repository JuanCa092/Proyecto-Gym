Use Case Note
■ Workflow
    • El entrenador accede al listado de sus clases asignadas.
    • Selecciona una clase en particular y presiona la opción "Ver Inscritos" o "Lista de Asistencia".
    • El sistema consulta en la base de datos las reservas/inscripciones activas asociadas a esa clase específica.
    • El sistema despliega el listado de los clientes inscritos con sus datos principales.
■ Business Logic
    • El entrenador solo debe poder consultar el listado de clientes pertenecientes a las clases que tiene asignadas bajo su cargo.
    • La lista debe reflejar los registros de inscripción en tiempo real (si un cliente cancela o se inscribe a última hora, la lista se actualiza).
    • La información mostrada debe respetar la privacidad del usuario, limitándose a datos de identificación y control (Nombre, Apellidos, Documento de Identidad y Correo electrónico).
■ Decisions
    • La lista se presentará ordenada alfabéticamente por el primer apellido del cliente para facilitar la toma de asistencia en el gimnasio.
■ Follow-up
    • Evaluar si en una fase futura se incluirá un botón para marcar directamente "Asistió / No asistió" (fuera del alcance del proyecto actual).

Scenario
Steps
1. El entrenador navega a la sección "Mis Clases Asignadas".
2. El entrenador selecciona una clase específica y hace clic en "Consultar Clientes Inscritos".
3. El sistema realiza la consulta en la base de datos obteniendo los clientes que poseen una reserva activa para esa clase.
4. El sistema despliega la lista detallada de asistentes con sus nombres, documento de identidad y correo electrónico.
