Description

El caso de uso permite a un usuario autenticado guardar o eliminar una rutina/clase deportiva dentro de su lista personal de favoritos para agilizar su consulta y permitir una inscripción rápida en el futuro      .

Use Case Note
■ Workflow
    • El usuario explora el catálogo o detalle de rutinas/clases disponibles.
    • Presiona el icono o botón "Guardar en Favoritos".
    • El sistema verifica que la sesión del usuario se encuentre activa.
    • El sistema guarda la asociación entre la rutina y el usuario en la base de datos.
    • La interfaz actualiza el icono notificando que la rutina ha sido añadida a favoritos.
■ Business Logic
    • Se requiere una sesión de usuario activa para asociar la rutina a la cuenta.
    • No se permite duplicar la misma rutina en la lista de favoritos de un usuario.
    • La acción funciona de manera conmutativa (toggle): presionar el botón sobre una rutina guardada la removerá de la lista.
■ Decisions
    • Las rutinas favoritas se almacenarán de forma persistente en la base de datos vinculadas al ID del usuario.
■ Follow-up
    • Validar si se requiere una pestaña dedicada llamada "Mis Rutinas Favoritas" dentro del perfil del usuario.

Scenario
Steps
1. El usuario selecciona el icono en la pantalla con el logo de una mancuerna.
2. El sistema despliega una lista de opciones de navegacion.
3. El usuario selecciona la opcion Rutinas de entrenamiento.
4. El sistema carga el modulo de Rutinas de entrenamiento.
5. El usuario selecciona la rutina de entrenamiento que desee visualiza.
6. El usuario desliza hacia abajo por la pantalla.
7. El usuario selecciona la opción "Guardar en Favoritos" (icono de marcadores o estrella).
8. El sistema valida la autenticación activa del usuario.
9. El sistema almacena la rutina dentro de la lista de favoritos del usuario en la base de datos.
10. El sistema confirma la acción mediante una notificación en pantalla y cambia el estado del botón a "Guardado".
