  Consultar rutina : Use Case

Permite a un usuario consultar las rutinas de entrenamiento disponibles en la plataforma, visualizando la lista de ejercicios, grupos musculares involucrados,numero de series,repeticiones y recomendaciones de ejecucion

  Registro usuario : Use Case

El caso de uso permite a un nuevo visitante registrarse en la plataforma GymLocator mediante el diligenciamiento de un formulario con sus datos básicos (nombres, documento de identidad, correo electrónico y contraseña)      . El sistema valida la información e ingresa el nuevo usuario en la base de datos para habilitar su posterior autenticación      . 

  Verificar usuarios existentes : Use Case

El caso de uso consulta y verifica la existencia de un usuario en la base de datos de GymLocator utilizando su correo electrónico o número de documento de identidad como criterio de búsqueda, previniendo registros duplicados o facilitando la búsqueda administrativa      .

  Iniciar sesión : Use Case

El caso de uso permite a un usuario registrado autenticarse en la plataforma GymLocator ingresando su correo electrónico y contraseña      . El sistema valida las credenciales recibidas y, si son correctas, otorga acceso a la plataforma dirigiendo al usuario al panel correspondiente según su rol (Cliente, Administrador o Entrenador)      .

  Cerrar Sesión : Use Case

El caso de uso permite a un usuario con una sesión activa finalizar su sesión dentro de la plataforma GymLocator      . El sistema destruye la sesión del usuario, elimina los tokens o credenciales temporales de la memoria y redirige a la vista pública principal o a la pantalla de inicio de sesión      . 

  Modificar perfil : Use Case

El caso de uso permite a un usuario autenticado consultar y actualizar la información de su perfil personal dentro de la plataforma GymLocator      . El usuario modifica los campos permitidos y el sistema valida e interactúa con la base de datos para almacenar los datos actualizados      .

  Consultar sedes : Use Case

El caso de uso permite a cualquier usuario o visitante consultar el listado general de las sedes de la red de gimnasios GymLocator y seleccionar una para visualizar sus detalles específicos, tales como dirección, horarios de atención, servicios disponibles y clases programadas      .

  Guardar sede en favoritos : Use Case

El caso de uso permite a un usuario autenticado guardar o remover una sede deportiva dentro de su lista personal de favoritos para facilitar el acceso rápido a su información y clases asociadas      .

  Verificar disponibilidad de cupos : Use Case

El caso de uso evalúa dinámicamente si una clase elegida por el usuario cuenta con al menos un cupo disponible en el sistema antes de proceder con el registro de la inscripción      .

  Guardar rutina en favoritos : Use Case

El caso de uso permite a un usuario autenticado guardar o eliminar una rutina/clase deportiva dentro de su lista personal de favoritos para agilizar su consulta y permitir una inscripción rápida en el futuro      .

  Inscribir a clase : Use Case

Permite a un usuario autenticado seleccionar e inscribirse en una clase programada disponible en una sede específica      . El sistema valida la disponibilidad de cupos y que el usuario no tenga inscripciones duplicadas antes de confirmar la reserva      .

  Consular clases inscritas : Use Case

El caso de uso permite a un usuario autenticado visualizar la lista detallada de todas las clases a las cuales se ha inscrito previamente, incluyendo la sede, especialidad, entrenador asignado y horario correspondiente      . 

  Cancelar inscripcion : Use Case

El caso de uso permite a un usuario autenticado cancelar una reserva previamente realizada sobre una clase deportiva, retirando el registro del usuario e incrementando en 1 el número de cupos disponibles para dicha clase      .

  Registrar entrenadores : Use Case

El caso de uso permite a un Administrador autenticado dar de alta a un nuevo entrenador en la plataforma GymLocator mediante el diligenciamiento de sus datos personales, credenciales de acceso y especialidad deportiva, asignándole automáticamente el rol de "Entrenador" en la base de datos.

  Agregar entrenador : Use Case

El caso de uso permite a un Administrador autenticado vincular un perfil de entrenador registrado previamente a una sede específica de la red GymLocator, definiendo su disponibilidad y perfil operativo en dicha ubicación.

  Consultar entrenadores : Use Case

El caso de uso permite a un Administrador autenticado consultar la lista completa de todos los entrenadores dados de alta en la plataforma GymLocator, mostrando su información de perfil (nombres, documento, correo electrónico, especialidad) y el estado de sus asignaciones.

  Consultar clientes : Use Case

El caso de uso permite a un Administrador autenticado visualizar la lista completa de todos los clientes registrados en el sistema GymLocator, mostrando información detallada como nombres, apellidos, documento de identidad, correo electrónico y estado de la cuenta.

  Crear sedes : Use Case

El caso de uso permite a un Administrador autenticado dar de alta una nueva sede deportiva en la plataforma GymLocator, ingresando datos fundamentales como nombre de la sede, dirección física, teléfono de contacto, horario de atención y aforo o capacidad máxima.

  Modificar Sede : Use Case

 

  • El caso de uso permite a un Administrador autenticado editar la información de una sede previamente existente en la plataforma GymLocator (nombre, dirección, teléfono, horario de atención y capacidad), actualizando sus registros en la base de datos.

 

  Crear clases entrenamiento : Use Case

El caso de uso permite a un Administrador autenticado programar y registrar una nueva clase de entrenamiento en la plataforma, definiendo el nombre de la disciplina, la sede donde se dictará, el entrenador encargado, la fecha, el horario y el límite de cupos disponibles.

 

  Modificar clases : Use Case

El caso de uso permite a un Administrador autenticado editar la información de una clase previamente creada en la plataforma GymLocator (nombre, entrenador asignado, sede, fecha, horario o aforo), actualizando los datos almacenados en el sistema.

  Consultar clases asignadas : Use Case

El caso de uso permite a un entrenador autenticado consultar la lista de clases deportivas que le han sido asignadas por el administrador, permitiéndole revisar la sede, especialidad, horario, fecha y número de cupos/asistentes registrados en cada sesión      .  

  Consultar clientes inscritos : Use Case

El caso de uso permite a un entrenador autenticado seleccionar una de sus clases asignadas y visualizar el listado completo de clientes inscritos en ella, mostrando sus nombres, documentos de identidad y datos de contacto básicos      .

  Asignar rutina : Use Case

El caso de uso permite a un entrenador autenticado seleccionar un cliente o grupo de clientes inscritos en sus clases y vincularles una rutina de ejercicios predefinida o personalizada, registrando los detalles de la asignación en la base de datos      .

  Crear rutinas : Use Case

El caso de uso permite a un entrenador autenticado diseñar y registrar una nueva rutina de ejercicios en la plataforma, definiendo su nombre, descripción, nivel de dificultad, series, repeticiones y la lista de ejercicios que la componen.

  Modificar rutinas : Use Case

El caso de uso permite a un entrenador autenticado editar la información de una rutina previamente registrada en el sistema (nombre, objetivo, nivel de dificultad o desglose de ejercicios), actualizando sus datos en la base de datos de GymLocator.

  Verificar datos : Use Case

El caso de uso evalúa la validez de los datos introducidos en un formulario (comprobando que no existan campos obligatorios vacíos, que el correo electrónico tenga un formato correcto y que los números o fechas cumplan la estructura requerida) antes de continuar con la lógica del negocio      .

  Consultar clases : Use Case

El caso de uso permite consultar el listado de clases deportivas programadas en la plataforma, filtradas o asociadas a una sede, mostrando detalles como la especialidad, el entrenador asignado, el horario de la sesión y los cupos disponibles      .
