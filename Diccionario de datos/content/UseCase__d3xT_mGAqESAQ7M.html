Use Case - Consultar sedes link

Description

El caso de uso permite a cualquier usuario o visitante consultar el listado general de las sedes de la red de gimnasios GymLocator y seleccionar una para visualizar sus detalles específicos, tales como dirección, horarios de atención, servicios disponibles y clases programadas      .

Use Case Note
■ Workflow
    • El usuario ingresa a la sección "Sedes" desde el menú principal de la aplicación.
    • El sistema consulta y despliega la lista de sedes registradas con datos generales (nombre, dirección y horario general).
    • El usuario selecciona una sede específica de la lista.
    • El sistema presenta la vista detallada de la sede elegida con sus servicios y la programación de clases asociadas.
■ Business Logic
    • La consulta es de acceso público o general (no requiere restricciones de rol estricto para ver las sedes).
    • Solo se muestran aquellas sedes que se encuentren registradas y activas en el sistema.
    • La información presentada debe sincronizarse en tiempo real con los registros administrados en la base de datos.
■ Decisions
    • No incluye integración con mapas externos o geolocalización por GPS (se mantiene dentro de los límites y restricciones del proyecto).
    • La vista detallada incluye directamente la oferta de clases de la sede seleccionada para facilitar la navegación.
■ Follow-up
    • Definir en versiones futuras si se habilitarán filtros de búsqueda por localidad o barrio en Bogotá (fuera del alcance actual).

Scenario
Steps
1. El usuario navega hacia la sección "Sedes" en la plataforma.
2. El sistema recupera y muestra el listado de todas las sedes registradas.
3. El usuario selecciona una sede para ver más detalles.
4. El sistema consulta la base de datos y despliega la información completa de la sede (dirección, horarios, descripción de servicios y lista de clases).
